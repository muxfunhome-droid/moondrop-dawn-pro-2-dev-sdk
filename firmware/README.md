# firmware/

**Language:** English · [Русский](README.ru.md)

Put **your own** images here: `firmware.bin` (an "SPV APP Tag" image, magic `SPV@`, build "Nov 17 2025 13:50:18") and the flash dump
taken from your device. `*.bin` files are ignored by git (`.gitignore`): the firmware belongs to the vendor, and a dump
contains a binding key unique to your chip.
