# life — игра «Жизнь» Конвея на поле 10×10, которую считает USB-ЦАП

**Язык:** [English](README.md) · Русский

ПК отправляет поле и число шагов, **RISC-V внутри ЦАПа** считает поколения и возвращает только итоговое поле.
Рисует его программа на ПК. Звук не трогается. Пока чип считает, LED горит зелёным.

Так рисует программа на ПК (глайдер через 4 шага — результат, который `test_emu.py` сверяет с эталоном):

## Сборка
```sh
scripts/build_app.sh life build/fw_custom2.bin build/fw_life.bin   # прошивка, с проверкой в эмуляторе
python3 -I sdk/examples/life/test_emu.py                           # 11 случаев против эталона на Python
make -C sdk/examples/life/host                                     # программа для ПК (Linux, без зависимостей)
```

## Использование (Linux)
```sh
life glider -n 4             # узоры: glider, blinker, toad, beacon, rpent, random[:seed]
life field.txt -n 100        # поле из файла: 10 строк, живая — # * o O X 1, мёртвая — . 0 пробел
life - -n 5 < field.txt      # поле из stdin
life glider -a 40 -t 100     # анимация: 40 поколений, каждое посчитано на чипе, 100 мс на кадр
life glider -n 4000000000    # миллиарды шагов: чип находит цикл и берёт остаток по модулю периода
life rpent -n 50 --no-wrap   # мёртвые края вместо тора
life random:7 -n 20 --plain  # итог текстом (можно снова подать как файл)
```

## Как устроено
- **Протокол** (vendor HID-отчёт 75, 64 байта): запрос `[75, 0xCB, seq, flags, steps u32 @4, поле 13 Б @8]`,
  ответ `[75, 0xCB, seq, status, steps u32 @4, поле 13 Б @8, время мкс u32 @24, население u8 @28, период u32 @32, найден на шаге u32 @36]`.
  Поле — 100 бит: клетка (строка r, столбец c) = бит `r*10 + c`, младший бит первого байта — левый верхний угол. `flags` бит 0 = мёртвые края.
- **Перехват** как в `calc`: заводской HID-обработчик `0x8d84` перенаправлен, отчёты с `0xCB` забираются, остальные уходят в заводской код.
- **Без блокировки.** Обработчик только копирует запрос, поколения считаются в `app_loop()` по `steps_per_pass` (500) за проход
  главного цикла, так что прошивка (HID-команды, вход в загрузчик) продолжает работать. Ответ уходит, когда всё досчитано.
- **Побитовый шаг.** Строка — 10-битная маска; число соседей для всех 10 клеток строки считается сразу побитовым сумматором.
- **Поиск цикла (Брент).** Состояние запоминается на шагах 1, 2, 4, 8…; когда поле совпало с запомненным, период известен,
  и оставшиеся шаги берутся по модулю периода. Глайдер на торе 10×10 — период 40, найден на шаге 104.

Статус: 🧪 проверено в эмуляторе (`test_emu.py`: глайдер, мигалка, блок, случайные супы, тор и мёртвые края, 4 000 000 001 шаг,
счёт в 74 прохода главного цикла). На железе ещё не запускалось.
